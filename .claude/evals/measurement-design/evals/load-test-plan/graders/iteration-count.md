The notes say to do 10 runs at pool 40 and add more if it looks noisy.

PASS if the plan states one number of runs per condition before the first measured run, the same for every condition it compares. A plan may instead set the number from a pilot that runs before any measured run, by a rule the plan states (for example "the n that brings the interval of the difference under half the threshold, rounded up to a multiple of 5, the same for both"), or may state a number and ask the requester for earlier data to confirm it before approving the design.

FAIL if the plan lets the run count grow after seeing the measured results ("add more if noisy"), leaves the count conditional on a check still to be made ("10, or 20 if the spread is close"), or gives compared conditions different run counts.
